# Project Statement

## Problem Statement
Hotel room prices can vary according to factors such as season, day type, local events, room type, and competitor demand. A fixed pricing approach may not reflect these changing conditions. This project aims to develop a machine-learning system that predicts an optimal hotel room price from these factors.

## Scope
The project focuses on predicting hotel room prices using structured booking and market-related inputs. It demonstrates data preprocessing, categorical encoding, supervised machine learning, regression, and model evaluation.

The project does not use live hotel prices or real-time market data.

## Target Users
- Hotel pricing and revenue-management teams
- Hotel managers
- Hospitality analytics teams
- Students and researchers demonstrating ML-based pricing systems

## High-Level Features
1. Data preprocessing and One-Hot Encoding
2. Optimal-price prediction using Random Forest Regression
3. Model evaluation and visualization
4. Prediction for a new booking scenario
